# Earlier manuscripts and writing references

The active simulation and NC-validation manuscript has moved to
[`../miso_tfa/manuscript`](../miso_tfa/manuscript), alongside the MATLAB
project that generates its figures. Build it with `buildManuscript` from
`miso_tfa`.

This folder contains earlier LaTeX and Word drafts, writing references, and
their editing tools. They are not required to run the active project or build
the current paper. `paper_draft_v2` belongs to the earlier manuscript workflow.
